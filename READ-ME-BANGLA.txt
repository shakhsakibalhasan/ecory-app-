SMS live করতে — তথ্য বাকি
আপনি “অন্য provider আছে” বলেছেন, কিন্তু নাম/API specification দেননি। Provider-এর নাম, official website/API documentation দিন; API key chat-এ দেবেন না। SMS provider-specific adapter না বসা পর্যন্ত SMS চালু করবেন না।
বর্তমান customer-sms worker-এর secure adapter contract SMS-ADAPTER-CONTRACT.txt-এ আছে। সরাসরি provider URL সেই format না মানলে কাজ করবে না। Provider-এর সঙ্গে format মেলানোর code আরও লাগবে। Credentials শুধু server Secrets-এ।
Adapter প্রস্তুত হলে SMS_BRIDGE_URL, SMS_BRIDGE_TOKEN server Secrets-এ দিন; তারপর Admin → Settings → Order ও Appointment SMS → Customer SMS চালু করুন। নতুন orders তখন queue হবে। আগে হওয়া orders backfill করে অযাচিত SMS পাঠানো হয় না।
Order save-এর পরে immediate wake-up আছে; existing every-minute notification cron queue fallback হিসেবে drain করে। ব্যস্ততায় delay হতে পারে; network/provider delivery guaranteed নয়। Cron প্রতি run-এ সর্বোচ্চ 4টি SMS claim করে।
SMS log accepted মানে provider গ্রহণ করেছে, handset delivery নয়। Timeout/unknown result automatic retry হয় না যাতে duplicate SMS/charge না হয়। 15 মিনিট stuck sending হলে worker unknown দেখাবে। Queue-এর 24 ঘণ্টার বেশি পুরোনো pending SMS automatic পাঠাবে না।

SMS link সরাসরি app-এ খোলার জন্য
Android manifest intent filters ও appUrlOpen handling যুক্ত আছে। আরও দরকার: সঠিক APK signing certificate-এর SHA-256 fingerprint দিয়ে ecory.app domain verification।
node scripts/write-android-app-links.mjs SHA256_FINGERPRINT
এতে public/.well-known/assetlinks.json তৈরি হবে; publish করে https://ecory.app/.well-known/assetlinks.json সঠিক JSON ও HTTP 200 দেয় কি না পরীক্ষা করুন। Private signing key/password দেবেন না। ভুল certificate হলে link browser-এ খুলবে। App install না থাকলেও browser-এ একই tracking page কাজ করবে। Doctor booking details দেখতে account login লাগবে। Tracking token link গোপন রাখুন।
